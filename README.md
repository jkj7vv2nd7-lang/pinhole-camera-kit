# ピンホールカメラ工作キット

サンペーパー（ソーラープリンティングペーパー／サイアノタイプ）で撮る、厚紙製ピンホールカメラの型紙キット。単体HTMLアプリ（自己完結・CDN不使用）。

## ファイル
- `index.html` — アプリ本体（デザイン選択・型紙6ページ・説明書・露出目安・印刷用画像の書き出し）
- `icon.png` / `icon-180.png` — ホーム画面アイコン（自作描画）
- `verify.js` — 自動検証（起動・幾何・デザイン切替・PNG寸法と較正線）
- `shot.js` — プレビュー画像の生成（確認用）

## 仕様
- 本体：幅140×高さ100×奥行き42mm（背面ホルダー装着時 約44mm）。厚紙0.5〜1mmに型紙を貼って組む前提
- 紙：L判（89×127mm）横向き。内寸138×98mmに収まる
- 焦点距離：約41.5mm（アプリ内表記は約41mm）。ピンホール最適 約0.23mm（d≒√(2.44λf)）、実用0.2〜0.25mm、F値 約180
- ネガ→ポジ変換ツール内蔵（写真を選ぶ→反転→保存、「白黒で見る」切替つき。処理は端末内のみ）
- ガイド：紙の表裏の見分け方（感光面は薄い黄緑〜クリーム色）とセット時の注意を収録
- 紙ホルダー：144×104mmパネル＋14mmフラップの被せ式（二重構造で遮光）。本体リム外形142mmに対し片側1mmのクリアランス
- 型紙：全6ページ（型紙4＋説明書2）。A4・100%実寸、各型紙ページに赤い5cm較正線
  - 型紙1 本体（十字展開図：前面・上面・底面・側面＋角のりしろ）
  - 型紙2 紙ホルダー（部品B）と小部品（シャッターC／レールD／ピンホール枠E／紙押さえ帯F／光漏れ止め帯G）
  - 型紙3 内張りA（前面H／ホルダーI／側面J／黒帯K）
  - 型紙4 内張りB（上下L）と予備部品（予備シャッターM／予備枠N／練習枠O／遮光帯P）
- デザイン：5種（シルバートップ＋黒／オールブラック／レッド／ブルー／グリーン）。ブランド名・ロゴなし。上面のダイヤル類は完成時に後ろから見て正しい向きになるよう逆向き印刷（アプリ内に注記あり）
- 印刷：アプリが各ページを300dpi PNG画像（A4ちょうど）として書き出す方式。裁ち合わせパズルで最終的に実機印刷できた「画像形式」の経路に合わせたもの。デザイン選択に追随できるよう、固定PDFではなくアプリ内生成にしている

## 検証済み（verify.js 全項目合格）
- 起動・ページエラー0、デザイン5種×6ページ描画、UI切替
- 幾何：紙の余裕（横11mm／縦9mm）、焦点距離、ホルダーのクリアランス、窓中心＝紙中心、全ページで部品のページ内収納と非重なり、較正線50mm（モデル値）
- PNG書き出し：全ページA4×300dpiの画素寸法一致、墨あり、較正線の実測596〜597px（50mm＝590.6px＋線幅分）
